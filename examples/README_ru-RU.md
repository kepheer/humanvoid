# Примеры

[English](README.md)

Сначала выполните `pnpm run build:clean`. Каждый пример импортирует локально собранный пакет.

| Режим           | Запуск                                                                                        | Результат                                                                                           |
| --------------- | --------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Только клиент   | Откройте репозиторий через статический сервер и перейдите к `examples/client-only/index.html` | Браузер выполняет и оценивает клиентские детекторы локально.                                        |
| Только сервер   | `node examples/server-only/server.mjs`                                                        | Сервер оценивает данные HTTP-запроса; payload не требуется.                                         |
| Клиент + сервер | `node examples/client-server/server.mjs`                                                      | Браузер получает challenge, собирает сигналы, отправляет их, а сервер проверяет и оценивает запрос. |
