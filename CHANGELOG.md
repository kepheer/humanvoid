## [1.0.0] - 2026-08-14

### Added

- Client, server and combined client-server APIs for scoring browser automation evidence.
- Tri-state signal reports (`true`, `false`, `null`), signed one-time challenges and optional crawler verification.
- Client checks for direct automation evidence and headless-oriented WebGL, canvas and OfflineAudio behaviour.
- A real browser harness covering the challenge, client collection and server-verdict path.
